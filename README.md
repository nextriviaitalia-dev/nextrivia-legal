# NexTrivia — documenti legali

Informativa sulla privacy e termini di servizio di NexTrivia, in italiano e inglese.

Stanno qui, e non sul server di gioco, per una ragione sola: l'URL della privacy dichiarato su App Store
Connect deve restare raggiungibile anche quando il server di gioco non lo è. Un server che cade è un
disservizio; un URL di privacy che cade è un problema di conformità.

I testi sono generati da `NexTrivia/Resources/Legal/*.md` nel repository dell'app, che è la fonte: le
stesse parole sono mostrate dentro l'app. Quando cambiano lì, vanno rigenerate anche qui.
